Privacy

This site presents preselected, reviewed lab captures. It does not accept visitor uploads or user accounts.

Data displayed

The visible analyses come from project lab captures already included in the public repository. Results can contain documentation-range network addresses, packet metadata and findings. The captures contain generated lab traffic, not visitor traffic.

Visitors

This application does not intentionally set account cookies or run advertising analytics. The hosting provider may process ordinary request metadata such as IP address, time, path and user agent to deliver the site. Do not submit private captures; upload requests are disabled.

Reports

Reports generated from the reviewed samples are available in full and redacted forms. Full reports may include lab capture hashes and endpoint metadata.
