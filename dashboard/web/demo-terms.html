This read-only site is an educational prototype using reviewed project lab captures.

Interpretation

Rule results cover limited conditions, and a passing rule does not certify a VPN. Capture-only results withhold the numeric risk score when required configuration evidence is absent. Synthetic traffic-profile inference does not establish the identity of a real application.

Availability

The site and result formats may change. Do not use the demo as the sole basis for an operational security decision. Visitor capture upload and live capture are unavailable on this public site.

Source and evidence

Project documentation and lab records are available in the linked repository. Review the evidence state and limitations shown with each result.
