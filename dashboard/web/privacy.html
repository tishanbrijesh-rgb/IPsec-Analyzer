PRODUCT INFORMATION

Privacy Policy

This page explains how the current locally hosted prototype handles capture data. It describes the software as built, rather than a future hosted service.

Updated 29 September 2026

Data you provide

When you select a PCAP or PCAPNG file, your browser sends the complete file to the analyzer running on the same computer. Captures can contain network addresses, packet payloads, timestamps and other sensitive information. Only analyze traffic you are authorized to handle.

How the data is used

The server reads the capture to identify visible IKE, ESP and AH traffic and to create packet, session, flow and rule results. Uploaded capture bytes are written to a temporary file during analysis and that file is removed when analysis finishes or fails. The current software does not use uploaded captures to train a model.

What remains after analysis

Results, including endpoint addresses, packet references and findings, stay in server memory. The server keeps up to 16 recent results. Older results are evicted when that limit is reached, and all in-memory results disappear when the server stops. The current interface has no individual result deletion control. The selected file remains on your own computer.

Sharing and external services

The current application makes no analytics or advertising requests and does not send captures or results to an external service. It uses no account cookies. The server is designed to bind to the local loopback address and rejects nonlocal clients. If an operator changes how it is hosted, these statements must be reviewed before use.

Logs and reports

The local web server may log request paths, client address, status codes and timing in its terminal output. Reports can be downloaded while their result remains in memory. Shared-copy exports omit capture identifiers, endpoint addresses and SPI values, but still include packet counts, rule findings and other metadata. Review every report before sharing it.

Questions and public deployment

For questions about a specific installation, contact the person operating that installation. This repository does not identify a public service operator or support address. A public deployment requires an operator-specific privacy notice, contact details and a legal review before accepting real user captures.
