HOSTED LAB WORKSPACE

Privacy

This password-protected prototype accepts authorized lab captures and optional sanitized configuration JSON. Do not upload production traffic, credentials or key material.

Processing

Your browser sends the entire capture and optional configuration to the hosted analyzer. Captures can contain addresses, timestamps and payload data. Raw capture bytes are written to a temporary file during analysis and removed when analysis finishes or fails. Uploaded data is not used for model training.

Results and retention

Analysis results, including endpoint metadata and findings, remain in the service's memory. Up to 16 recent results are kept; older results are evicted and all results disappear when the process restarts. There is no individual deletion control. Reports are available while a result remains in memory.

Hosting and access

The service uses a shared password over HTTPS. Anyone with that password can view stored results and reports. The hosting provider may process request metadata and infrastructure logs. This prototype has no individual accounts or audit trail. Keep the password private and use only approved lab data.
