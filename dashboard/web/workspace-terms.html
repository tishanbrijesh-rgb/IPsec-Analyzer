Terms

This is an educational analysis prototype for authorized lab traffic.

Authorized use

Only upload captures and sanitized configuration snapshots that you are permitted to process on this hosted service. Do not include credentials, private keys or production traffic.

Interpretation

Rule results cover limited conditions. A passing rule does not certify a VPN. Packet observations, configured values, installed state and model inferences have different evidence strengths. Read each result's evidence state and limits before acting on it.

Availability

Results are held only in memory and can disappear when the service restarts. This prototype is not a durable evidence store or a replacement for professional review.
